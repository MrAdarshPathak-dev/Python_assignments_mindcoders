## What I learned

- How to store and convert values, and inspect Python data types.
- How to work with strings and common collection types.
- How to use conditions to make decisions and validate input.
- How to use `for` and `while` loops for repetition and accumulation.
- How to break down problems involving number properties, sequences, and patterns.
- How to organize practice prompts, notes, and solutions by topic.

## Examples of solved problems

- Calculate arithmetic operations and manipulate strings, lists, tuples, and sets.
- Classify numbers and calculate results such as grades, discounts, or eligibility using conditions.
- Generate multiplication tables, totals, prime-number checks, and Fibonacci terms with loops.
- Check palindromes and number properties such as Armstrong and perfect numbers.
- Print star and numeric patterns using nested loops.
