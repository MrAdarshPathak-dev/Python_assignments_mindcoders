# Number Concepts

- **Armstrong number:** A positive integer equal to the sum of its digits, each raised to the power of the number of digits. For example, `153 = 1³ + 5³ + 3³`.
- **Perfect number:** A positive integer equal to the sum of its positive divisors, excluding itself. For example, `6 = 1 + 2 + 3`.
- **Digital sum:** The sum of all the digits in a number. For example, the digital sum of `472` is `4 + 7 + 2 = 13`.
- **Decimal to binary:** Decimal is base 10, while binary is base 2 and uses only `0` and `1`. To convert a decimal whole number, repeatedly divide it by `2` and record each remainder; read the remainders from last to first. For example, `13` in decimal is `1101` in binary.
- **Fibonacci sequence:** A sequence commonly starting with `0, 1`, where each new term is the sum of the two terms before it. It begins `0, 1, 1, 2, 3, 5, 8, 13, ...`; for example, `5 + 8 = 13`.
- **Prime number:** A whole number greater than `1` that has exactly two positive divisors: `1` and itself.
- **LCM (Least Common Multiple):** The smallest positive number that is divisible by both given numbers.
- **HCF (Highest Common Factor):** The greatest positive number that divides both given numbers exactly; also called the GCD.
